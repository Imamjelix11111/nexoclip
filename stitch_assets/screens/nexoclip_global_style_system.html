# NexoClip — Global Style System Design a SaaS web application called **NexoClip**, an AI-powered video content creation and distribution studio for Indonesian content creators and digital marketers. ## Identity - App name: NexoClip - Tagline: AI Video Production Studio - Tone: Professional, modern, editorial. Like a high-end creative agency tool — not a startup toy. - Audience: Indonesian TikTok/YouTube creators and performance marketers. ## Color Palette | Token | Hex | Usage | |---|---|---| | Background | #f8fafc | Page/app background | | Surface | #ffffff | Cards, panels | | Border | #e2e8f0 | Dividers, card borders | | Text Primary | #0f172a | Headings, important text | | Text Secondary | #475569 | Body text | | Text Muted | #94a3b8 | Labels, placeholders, metadata | | Accent | #D97757 | CTAs, active states, highlights | | Accent Light | #D97757/10 | Active item bg, badge bg | | Success | #10b981 | Completed status | | Error | #ef4444 | Failed status | | Warning | #f59e0b | Pending/warning | ## Typography -
