# Auth Database Foundation Design

## Goal

Add the smallest raw-PostgreSQL foundation for future server-side sessions without changing existing BYOK compatibility behavior.

## Scope

This slice adds:

- A `pg` connection pool using `DATABASE_URL`.
- An idempotent SQL migration runner.
- `users` and `sessions` tables suitable for hashed opaque session tokens.
- A `.env.example` documenting required database configuration.

This slice does not add login UI, OAuth, password authentication, workspace membership, or changes to existing MuAPI routes.

## Data model

`users` stores the application identity with a stable UUID, optional email, display name, and timestamps.

`sessions` stores a stable UUID, a foreign key to `users`, only a SHA-256 token hash, expiry, optional revocation timestamp, and timestamps. A unique constraint on the token hash prevents duplicate sessions. Deleting a user cascades to their sessions.

## Migration approach

Migrations are plain SQL files under `src/db/migrations`, named with a numeric prefix. The runner creates a `schema_migrations` table, executes unapplied files in lexical order inside a transaction, and records each filename only after successful execution. The runner requires `DATABASE_URL` and exits non-zero on failure.

## Runtime behavior

`src/db/pool.js` exports one lazily-created `pg.Pool`, configured from `DATABASE_URL`. The pool is reused across calls and does not connect during module import. `closePool()` is provided for scripts/tests.

## Security

No raw session token is stored in PostgreSQL. The schema is prepared for an opaque random token generated by a later auth service. Existing `muapi_key` storage and forwarding remain untouched.

## Verification

- Static syntax/import verification for the migration runner and pool.
- Migration runner must fail clearly when `DATABASE_URL` is absent.
- If a local PostgreSQL server is available, run the migration twice and confirm the second run is a no-op.
- Review `git diff` and confirm no secrets or production compatibility routes changed.
